## 1. 核心哲学

### 1.1 双轨并行：GTO + 可剥削

本项目的核心策略不是纯粹的 GTO，也不是单纯的读人打法，而是 **以 GTO 为基础，动态切换可剥削模式**：

```
默认模式：GTO（无懈可击的基础线）
         ↓ 检测到对手失误模式
可剥削模式：最大化利用对手偏差
         ↓ 对手调整后回归
默认模式：GTO
```

- **GTO** 保证我们不被剥削，同时从对手的犯错中获利
- **可剥削** 在我们识别对手模式时进一步最大化 EV（期望值）
- 对战 AI 时，GTO 更重要；对战弱鱼时，可剥削更重要

### 1.2 最高原则：期望值（EV）最大化

每一个决策的唯一标准是 **长期 EV 最大化**，而非单局结果。

## 2. 牌力等级与基础概念

### 2.1 牌型从强到弱

| 等级 | 牌型 | 示例 |
|------|------|------|
| 1 | 皇家同花顺 | A K Q J T (同花) |
| 2 | 同花顺 | 9 8 7 6 5 (同花) |
| 3 | 四条 | A A A A x |
| 4 | 葫芦 | K K K 7 7 |
| 5 | 同花 | 任意5张同花 |
| 6 | 顺子 | 8 7 6 5 4 |
| 7 | 三条 | Q Q Q x x |
| 8 | 两对 | J J 9 9 x |
| 9 | 一对 | 8 8 x x x |
| 10 | 高牌 | A K Q J 9 |

### 2.2 出牌位置（9人桌）

```
位置顺序（相对庄家）：
UTG (Under the Gun) → UTG+1 → UTG+2 → LJ (Lojack) →
HJ (Hijack) → CO (Cutoff) → BTN (Button) → SB → BB

位置越靠后越有利：
- BTN 是最佳位置（永远最后行动）
- UTG 是最差位置（第一个行动）
- SB 翻牌后永远第一行动（最差翻牌后位置）
```

### 2.3 核心术语

- **Range（范围）**：某位置可能持有的所有手牌集合
- **Equity（胜率）**：当前手牌赢得底池的概率
- **EV（期望值）**：某一行动的长期平均收益
- **Pot Odds（底池赔率）**：底池大小与跟注额之比
- **SPR（Stack-to-Pot Ratio）**：剩余筹码与底池之比，影响决策深度

## 3. 翻牌前策略（Preflop）

### 3.1 开牌范围（9人桌，100BB深度）

翻牌前是 GTO 最容易被精确执行的街，范围如下：

#### UTG（约 13-15% 范围）
```
AA KK QQ JJ TT 99 88 77
AKs AQs AJs ATs A9s
KQs KJs KTs
QJs QTs
JTs
AKo AQo AJo KQo
```

#### UTG+1 / UTG+2（约 15-17%，稍宽）
```
加入：66, A8s, A7s, KTs→K9s, T9s, 98s
```

#### HJ / Lojack（约 18-20%）
```
加入：55 44, A6s-A5s, K8s-K7s, Q9s, J9s, T8s, 87s, 76s
```

#### CO（约 25-28%）
```
加入：33 22, A4s-A2s, K6s-K4s, Q7s, J8s, 97s, 86s, 75s, 65s
还有一些低质量 offsuit 高牌组合
```

#### BTN（约 45-55%）
```
几乎所有有价值的手牌，包括：
22+, A2s+, K2s+, Q2s+, J3s+, T3s+, 95s+, 85s+, 74s+, 64s+, 53s+, 43s
A2o+, K5o+, Q8o+, J8o+, T7o+, 97o+, 87o
```

#### SB（约 35-45%，主要偷盲或3bet）
```
相对 BTN 稍紧，但面对单人跛入时 allin/fold 或 3bet 为主
避免跟注，因为翻牌后位置永远最差
```

#### BB（宽范围防守 + 3bet）
```
由于已投入 1BB，BB 的 MDF（最低防守频率）非常高
面对单人开牌：约 70-75% 的情况应防守（跟注或 3bet）
3bet 频率约 8-12%（价值 + 半诈唬混合）
```

### 3.2 3-Bet 策略

#### 3-Bet 价值范围
```
AA, KK, QQ, JJ (始终3bet)
AKs, AKo (始终3bet)
AQs (大多数位置3bet)
TT, 99 (部分混合策略)
```

#### 3-Bet 诈唬/半诈唬范围
选择具有以下特性的手牌：
- **阻挡对手强牌**（如 Axs 阻挡 AA）
- **翻牌后有潜力**（同花连牌）
- **纯垃圾牌不适合3bet**（折叠即可）

```
典型 3-bet 诈唬手牌：
A5s, A4s, A3s, A2s（阻挡 AA，有同花顺潜力）
KQs（部分位置混合3bet）
JTs, T9s（连牌，被跟注后有胜率）
```

#### 3-Bet 尺寸
| 位置关系 | 3-Bet 尺寸 |
|----------|-----------|
| 有位置（IP） | 约 3x 对手开牌额 |
| 无位置（OOP） | 约 4-4.5x 对手开牌额 |

### 3.3 4-Bet 策略

4-Bet 价值：AA, KK（始终），有时 QQ / AKs
4-Bet 诈唬：A5s, A4s（阻挡 AA/KK，有同花顺潜力）

4-Bet 频率约为 3-Bet 频率的 20-30%（保持平衡）

### 3.4 关键翻牌前原则

1. **不跛入（No Limping）**：要么开牌加注，要么弃牌
2. **位置决定范围**：越靠后范围越宽
3. **不用弱牌 3-Bet**：纯垃圾牌应弃牌，不做轻率3bet
4. **SPR 影响决策**：浅筹码时范围收窄，偏向高牌和对子

## 4. 翻牌后策略（Postflop）

### 4.1 牌面纹理分类

#### 干燥牌面（Dry Board）
特征：彩虹（无同花），无连牌，无对子潜力
示例：K♠ 7♦ 2♣

策略：
- 持强牌用小注（25-33% 底池）保护范围
- 用大量手牌 c-bet，因对手范围弱
- 低弃牌率，小注更合适

#### 湿润/动态牌面（Wet Board）
特征：两张同花或顺子连接
示例：J♥ T♠ 8♥

策略：
- 用较大注保护（50-75% 底池）
- 选择性 c-bet，因对手摸牌多
- 需要更强的手牌才适合投入多街

#### 配对牌面（Paired Board）
示例：K♠ K♦ 7♣

策略：
- 范围优势转移给 BTN/开牌者（更多 K 在其范围）
- 可以用小注频繁 c-bet
- 被加注时需谨慎

### 4.2 翻牌后下注尺寸策略

| 场景 | 推荐尺寸 |
|------|---------|
| 干燥牌面（极化范围） | 25-33% 底池 |
| 干燥牌面（合并范围） | 33-50% 底池 |
| 湿润牌面 | 50-75% 底池 |
| 转牌双桶（二次下注） | 66-80% 底池 |
| 河牌（极化） | 75-100% 底池 |
| 坚果优势（Nut Advantage） | 超底池（100%+） |
| 3-Bet 底池 c-bet | 25-40% 底池（小注） |

### 4.3 三街（Three Streets）价值提取

强牌（两对以上）策略：
```
翻牌：中/大注建底池
转牌：持续加压（66%+ 底池）
河牌：大注或超底池提取价值
```

中等强牌（一对/顶对）策略：
```
翻牌：根据牌面选择注大小
转牌：如对手跟注，评估是否继续
河牌：谨慎下注，避免被强牌反超
```

摸牌（Draws）策略：
```
有13张以上出路（同花+顺）：主动下注，增加赢得底池方式
9-12张出路（同花 / OESD）：选择跟注或半诈唬下注
少于 6 张出路：通常跟注或弃牌，视赔率而定
```

### 4.4 C-Bet（翻牌后持续下注）决策框架

```
是否 c-bet 的决策树：

1. 牌面优势（Range Advantage）？
   我方范围在此牌面是否更强？
   → 是：倾向 c-bet
   → 否：倾向 check

2. 坚果优势（Nut Advantage）？
   我方持有超强牌比例是否更高？
   → 是：可以用大注或超底池
   → 否：用小注或 check

3. 位置（Position）？
   有位置：更灵活，可以选择 check-back 控池
   无位置：需要 c-bet 保护弱摸牌，但也需防止过度 c-bet

4. 对手特征？
   折叠率高：增加诈唬 c-bet
   跟注率高：只用价值牌 c-bet，减少诈唬
```

#### 实现中的具体阈值（基于 Pluribus 多路研究）

| 场景 | 胜率阈值 | 说明 |
|------|---------|------|
| 强价值手（单挑） | equity ≥ 0.65 | 始终下注（顶对以上均属此类） |
| 强价值手（多路） | equity ≥ 0.65 | 频率略降（3路 ~85%，4路 ~75%） |
| 半诈唬（多路底池） | equity ≥ 0.45 | 多路底池最低要求，低于此直接放弃 |
| 半诈唬（单挑） | 0.30 ≤ equity ≤ 0.65 | 正常频率，结合牌面湿润度 |
| 纯空气 | equity < 0.20 | 需对手弃牌率 > 40% 才考虑下注 |

注：价值门槛从原先 0.70 降低至 **0.65**，捕捉顶对/一对中踢脚等薄价值手的价值提取机会。

### 4.5 转牌（Turn）策略

- 翻牌 check-check 后，转牌出牌频率提高（"延迟 c-bet"）
- 对手跟注翻牌后，继续施压需要更强的手牌或更好的摸牌
- 转牌是摸牌手决定是否继续的关键节点（赔率重新计算）

### 4.6 河牌（River）策略

河牌是最极化（polarized）的一街：
- **价值注**：下注期望被更差牌跟注
- **诈唬注**：未完成摸牌，没有摊牌价值时考虑诈唬

**核心原则：河牌没有半诈唬（Semi-bluff）**

翻牌/转牌的半诈唬成立，是因为"即使被跟注，还有出路（outs）"。
河牌无牌可来，出路归零，因此"半诈唬"在河牌街是逻辑矛盾。

河牌行动只有三类：
1. **价值下注**：equity ≥ 0.60，期望更差牌跟注
2. **纯诈唬**：equity < 0.35（无摊牌价值），且对手弃牌率 > GTO 盈亏平衡线（约 40%）
3. **过牌/弃牌**：上述两种条件均不满足

```
GTO 河牌诈唬盈亏平衡弃牌率：
下注 50% 底池 → 对手需弃牌 > 33% 才盈利
下注 66% 底池 → 对手需弃牌 > 40%
下注 100% 底池 → 对手需弃牌 > 50%
```

河牌诈唬候选手牌：
- 未完成的同花摸牌（完全没有摊牌价值）
- 错过的顺子摸牌
- 高牌（A高或K高，无对子）且持有阻挡效应（blockers）

## 5. 数学基础：赔率、胜率与期望值

### 5.1 底池赔率（Pot Odds）

```
底池赔率 = 底池大小 / 需跟注的金额
所需胜率 % = 跟注金额 / (底池 + 跟注金额)

示例：底池 100，对手下注 50
最终底池 = 100 + 50 + 50 = 200
所需胜率 = 50 / 200 = 25%
→ 只要胜率 > 25%，跟注有正 EV
```

### 5.2 不同注额对应的所需胜率

| 下注（占底池比例） | 底池赔率 | 所需胜率 |
|---------|---------|---------|
| 25% | 5:1 | 17% |
| 33% | 4:1 | 20% |
| 50% | 3:1 | 25% |
| 66% | 2.5:1 | 29% |
| 75% | 2.33:1 | 30% |
| 100% | 2:1 | 33% |
| 150% | 1.67:1 | 38% |

### 5.3 出路计算（Rule of 2 and 4）

```
翻牌后（还有转牌+河牌）：出路数 × 4 ≈ 胜率%
转牌后（只剩河牌）：出路数 × 2 ≈ 胜率%

常见摸牌出路：
同花摸牌：9 张出路 → 翻牌约 36%，转牌约 18%
两头顺（OESD）：8 张出路 → 翻牌约 32%，转牌约 16%
中间顺（Gutshot）：4 张出路 → 翻牌约 16%，转牌约 8%
同花 + 两头顺：15 张出路 → 翻牌约 60%，转牌约 30%
```

### 5.4 隐含赔率（Implied Odds）

当底池赔率不够但未来可以赢更多筹码时，考虑隐含赔率。

```
隐含赔率适用条件：
1. 对手有较深筹码
2. 对手倾向于在你完成摸牌后付大注
3. 你的摸牌"隐蔽"（对手难以识别你完成了什么）

同花摸牌的隐含赔率通常比顺子摸牌好
（同花完成后更难被看穿）
```

### 5.5 期望值（EV）计算

```
EV = (胜率 × 赢得金额) - (败率 × 输掉金额)

示例：底池 100，需跟注 50（胜率 30%）
EV(跟注) = 0.30 × 150 - 0.70 × 50
         = 45 - 35
         = +10（正 EV，应该跟注）
```

### 5.6 最低防守频率（MDF）

```
MDF = 底池 / (底池 + 下注额)

示例：对手下注半底池
MDF = 100 / (100 + 50) = 67%

含义：如果你折叠超过 33% 的范围，对手纯诈唬有正 EV
策略：用 MDF 确保自己不被过度诈唬
```

## 6. GTO 核心原则

### 6.1 平衡范围（Balanced Ranges）

GTO 的核心是让对手无法利用你的行动模式：

```
每个下注尺寸都需要包含：
价值手牌（Value） + 诈唬手牌（Bluff）

比例原则（基于下注额）：
下注额 / (下注额 + 底池) = 最优诈唬比例

示例：下注 1/2 底池
最优诈唬频率 = 0.5 / 1.5 = 33%
→ 每下注 2 次价值，诈唬 1 次
```

### 6.2 混合策略（Mixed Strategies）

GTO 求解器经常给出"混合"建议，例如：
- 同一手牌 40% 加注，60% 跟注
- 这种随机性防止对手读取你的行动规律

在实现中，使用 **概率采样**（按频率随机选择动作）来模拟混合策略。

### 6.3 位置优势的量化

```
有位置（IP）的长期优势来自：
1. 最后行动权：可以获取免费牌或控制底池
2. 范围优势：开牌者范围更优质
3. 信息优势：先看对手行动再决策

无位置（OOP）的补偿策略：
1. 3-Bet 更频繁（减少 IP 玩家的位置优势）
2. check-raise 频率提高
3. Donk-bet（引导下注）在特定牌面
```

### 6.4 范围优势 vs 坚果优势

```
范围优势（Range Advantage）：
一方的平均手牌强度高于另一方
→ 倾向于频繁小注

坚果优势（Nut Advantage）：
一方持有最强牌（坚果）的频率更高
→ 倾向于大注/超底池
→ 即使对手有范围优势，坚果优势方可以超底池极化
```

## 7. 可剥削性策略（Exploitative Play）

### 7.1 识别对手类型

| 类型 | 特征 | 应对策略 |
|------|------|---------|
| 鱼（Fish/Calling Station） | 过度跟注，很少弃牌 | 减少诈唬，增大价值注 |
| 弱紧（Nit） | 极少进入底池，遇到阻力立刻弃牌 | 频繁偷盲，大量诈唬 |
| 弱松（LAG but bad） | 进入底池多但决策差 | 用强牌价值提取，耐心等待 |
| 过度激进 | 3-bet 太频繁，大量诈唬 | 跟注范围加宽，陷阱手牌增多 |
| GTO 玩家 | 接近均衡，难以读取 | 回归 GTO，不做额外偏差 |

### 7.2 关键可剥削调整

```
对手过度折叠（Fold Too Much）：
→ 增加诈唬频率（高于 GTO 推荐值）
→ 小注 c-bet 更频繁
→ 3-bet 更频繁以偷取底池

对手过度跟注（Call Too Much）：
→ 减少/消除诈唬
→ 只用强牌下注
→ 增大价值注尺寸提取更多 EV

对手过度加注（Raise Too Much）：
→ 用陷阱手牌（强牌跟注后 check-raise）
→ 弃牌弱摸牌，只留强摸牌和强牌
→ 宽化继续范围，减少过度弃牌

对手 3-bet 太少（Under 3-bet）：
→ 扩大开牌范围
→ 减少 4-bet 诈唬（因为他们 3-bet 时通常有价值牌）
```

### 7.3 针对 AI 对手的调整

当对战其他 AI bot 时：
1. 首先观察 50-100 手牌，建立对手的行为模型
2. 检测对手是否有系统性偏差（总是特定尺寸下注、特定频率诈唬）
3. 如果对手是纯 GTO，回归 GTO；如果有偏差，可剥削

## 8. 诈唬策略

### 8.1 最优诈唬频率

```
河牌诈唬（根据下注额）：

下注 50% 底池 → 诈唬频率 33%（1 诈唬 : 2 价值）
下注 75% 底池 → 诈唬频率 37.5%
下注 100% 底池 → 诈唬频率 50%（1:1）
下注 150% 底池 → 诈唬频率 60%

公式：最优诈唬频率 = 下注额 / (下注额 + 底池)
```

### 8.2 最佳诈唬候选手牌

选择具有以下特征的手牌作为诈唬：

1. **阻挡效应（Blockers）**：持有对手强牌的关键牌
   - 例：河牌出现 A 时，持有 A 的手牌诈唬更好（减少对手持有顶对/两对的概率）

2. **无摊牌价值**：弃牌后无法赢得底池的手牌
   - 未完成的摸牌（最常见的诈唬候选）

3. **有折叠权益**：对手在这个牌面上持有弱牌的概率高

### 8.3 翻牌/转牌半诈唬

半诈唬（Semi-bluff）：既有摸牌胜率，又有诈唬权益

```
优先级排序：
1. 同花摸牌 + 顺子摸牌（最强，约 50-60% 胜率）
2. 同花摸牌（9 张出路，约 36% 胜率在翻牌后）
3. 两头顺（8 张出路）
4. 中间顺 + 超牌（Overcards）

半诈唬策略：
- 有位置：可以选择跟注或下注（更灵活）
- 无位置：倾向于下注（保护范围，避免对手免费看牌）
```

### 8.4 诈唬失败的常见场景（避免）

- 对手跟注倾向高（Calling Station）
- 多人底池（诈唬成功概率按指数降低）
- 牌面对对手范围有利时
- 自身形象已经是"松"时

## 9. 多人底池策略

### 9.1 多人底池的核心原则

```
随着参与人数增加：
- 诈唬成功率显著降低
- 价值手牌需要更强（因为有更多对手）
- 摸牌的隐含赔率增加（多人付款）
- 更偏向摊牌路线
```

### 9.2 多人底池调整

| 人数 | 策略调整 |
|------|---------|
| 2人（HU） | GTO 最完整，可以较频繁诈唬 |
| 3人 | 诈唬减少 40-50%，需要更强价值牌 |
| 4人+ | 几乎不考虑纯诈唬，专注于价值 + 摸牌 |

## 10. 筹码深度调整

### 10.1 不同筹码深度策略

#### 深筹码（80BB+）
```
- 同花连牌、中小对子价值提升（隐含赔率大）
- SPR 高，摸牌值得追逐
- 更多 3-bet/4-bet 博弈
- 翻牌后决策复杂，分多街提取价值
```

#### 中等筹码（40-80BB）
```
- 标准开牌/3-bet 策略适用
- SPR 约 4-8，翻牌后结果已基本确定
- 中小对子价值下降
```

#### 浅筹码（20-40BB）
```
- 重点转向高牌和高对（翻牌前已接近全押）
- 同花连牌价值大幅下降
- 常见 Shove-or-Fold 策略
- 使用推注/弃牌（Jam/Fold）图表
```

#### 超浅筹码（< 20BB）
```
- 几乎只有推注（All-in）或弃牌两个选项
- 完全依赖 ICM 调整（锦标赛场景）
- Nash Push/Fold 图表为核心参考
```

### 10.2 SPR（筹码底池比）决策框架

```
SPR = 有效筹码 / 当前底池大小

SPR < 2：  超浅，强牌应全力押注
SPR 2-5：  浅，单强对子可以 100% 跟注全押
SPR 5-12： 中等，标准三街价值提取
SPR > 12： 深，需谨慎投入，适合同花/顺子摸牌
```

### 11.2 CFR 算法选择

基于学术研究（Libratus/Pluribus）的最优方案：

```
推荐：Monte Carlo CFR（MCCFR）+ 实时子博弈求解

分层实现：
1. 离线阶段：用 MCCFR 计算蓝图策略（Blueprint Strategy）
   - 手牌抽象（Hand Abstraction）：将相似手牌归类
   - 行动抽象（Action Abstraction）：限制下注选项（1/3, 1/2, 2/3, 全押等）

2. 实时阶段：子博弈求解（Endgame Solving）
   - 从当前博弈节点重新求解
   - 更精确但计算量更大
   - 只在关键节点触发（大底池、河牌等）
```

### 11.3 胜率计算与范围压缩折扣

实际计算分两步：

**步骤一：蒙特卡洛原始胜率（对随机手）**
```python
# 蒙特卡洛胜率估算（当前实现）
def calculate_equity(hole_cards, board, num_opponents, iterations=1000):
    wins = 0
    for _ in range(iterations):
        # 从剩余牌堆随机抽取对手手牌（随机手假设）
        opponent_cards = sample_from_deck(hole_cards, board, num_opponents)
        remaining_board = complete_board(board)
        if evaluate_hand(hole_cards, remaining_board) > best_opp(opponent_cards, remaining_board):
            wins += 1
    return wins / iterations  # raw_equity
```

**步骤二：Libratus式范围压缩折扣**

原始胜率高估了我们的实际胜率——对手不是随机手，其行动提供了范围信息：
- 每次加注/下注后，对手的实际范围收缩至当前的约 45%
- 对手三街连续下注后，其范围约为全部手牌的 5-10%（只有强牌）

```python
# HandRangeEstimator 范围折扣（range_estimator.py）
range_fraction = initial_vpip
for each_opponent_action:
    if action == 'raise': range_fraction *= 0.45
    if action == 'call':  range_fraction *= 0.75
    if action == 'check': range_fraction *= 0.92

# 分段线性插值折扣曲线（校准自 PioSolver 研究数据）：
# range=1.00 → discount=1.00（随机手，无折扣）
# range=0.30 → discount=0.79（对手范围收缩，实际胜率降低约21%）
# range=0.08 → discount=0.57（三街施压后，胜率大幅折扣）

effective_equity = raw_equity * discount_factor
```

此机制直接解决了"对手连续多街施压后仍用随机手胜率做决策"的核心缺陷。

### 11.4 手牌抽象（Hand Abstraction）

德州扑克有 1326 种起手牌组合，翻牌后状态空间爆炸。
使用以下方法压缩状态空间：

```
1. 起手牌分类（169 种类型）
   - 对子（13种）
   - 同花非对（78种）
   - 不同花非对（78种）

2. 翻牌后手牌桶（Bucketing）
   使用 K-means 聚类将相似胜率手牌归入同一桶
   典型桶数：翻牌 5000桶，转牌 1000桶，河牌 500桶

3. 公共信息提取
   - 牌面湿润度（Wetness）
   - 我方范围优势
   - 坚果优势归属
```

## 12. Bot 对战要点

### 12.1 对战 GPT 等 AI 的预期优势

GPT 等通用 LLM 在扑克中可能存在的弱点：
1. **无概率混合策略**：LLM 倾向于确定性输出，容易被读取
2. **不平衡的范围**：缺乏精确的范围构建
3. **糟糕的诈唬频率**：要么过多要么过少
4. **忽视底池赔率**：未必进行精确数学计算

PokerFate 的优势：
1. 精确的概率计算（蒙特卡洛模拟）
2. 基于 GTO 的平衡范围
3. 对手建模和可剥削调整
4. 混合策略随机采样（防止被读取）

### 12.2 对战基准测试

```
评估指标（每1000手）：
- BB/100（每100手赢得的大盲注数）> 10 为优秀
- 期望值曲线（应该稳定上升）
- 各位置的 VPIP / PFR 统计
- 不同对手类型的胜率
```

### 12.3 反作弊/反利用机制

```
防止被对手利用的关键：
1. 混合策略（不要 100% 确定性行动）
2. 下注尺寸多样化（不只用一种尺寸）
3. 定期"重置"可剥削调整（避免对手反向利用）
4. 随机化翻牌前行动时机（防止时序推断）
```
