# Web 牌局与资金看板

本机 Web 随 headless 或 proxy 启动，默认访问 <http://127.0.0.1:9022>；局域网内使用电脑 IP 和端口 `9022`。
VPS 的独立观看服务见[远程 Live 部署](remote_live/README.md)。

## 页面与数据来源

两种入口都提供实时牌桌、决策依据、上一手结算、资金看板、历史对局和活动雷达。
实时状态来自共用的 `LiveTableObserver`，资金来自同一轮 bot 统计，历史对局读取本地策略日志。
远程上传默认开启，配置缺失或不可用时记录原因并跳过。

实时牌桌和资金页与 VPS 共用展示组件。对局盈亏按服务端逐手结算累计，买入、补码不计作盈利；
活动奖励另行累计，领取与消费口径见[奖励记账](../pf_intercept/headless/lobby/README.md#记账与排错)。

## 结算与亮牌

“上一手”面板显示本手公共牌、赢家和自己的最佳五张及牌型，同时列出服务器公开的其他玩家底牌。
参与组合的底牌用金色标记；平分底池或多个边池赢家分别列出。结算面板保留到下一次结算，当前牌桌继续更新。

自己提前弃牌时，仍按本手实际发出的公共牌计算组合。公共牌不足或对手底牌未完全公开时，
不补造牌面或推测隐藏底牌；服务端提供了牌型时可展示该牌型。
采集和牌型计算在本机 observer 完成，VPS 只显示快照。

## 监听与开关

两种入口使用相同参数：`--web-host` 默认 `0.0.0.0`，`--web-port` 默认 `9022`，`--no-web` 关闭本机 Web。
`--no-remote-live` 关闭远程上传，两者互不影响。
本机 Web 没有观看登录验证；需限制为本机访问时，将监听地址设为 `127.0.0.1`。

## 更新与排错

静态页面修改后刷新浏览器即可；Python 数据采集或服务代码变更需要重启对应进程。
VPS 页面更新使用部署命令，不会重启本机 bot。

Web 自行追加写入 `pf_entertainment/logs/web.log`，内容包括启动、访问地址和请求处理异常。
牌局决策、网络连接和活动日志由各自模块保存，路径见[日志](../README.md#日志)。
`/api/live` 的 `available` 表示是否已接入快照源；`false` 与“已接入但当前在大厅”是不同状态。
